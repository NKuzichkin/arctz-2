# Механическая конструкция

> **DRAFT** — конструкция ещё не спроектирована. Документ фиксирует известные
> вводные и вопросы, требующие решения до начала проектирования/закупки.

## Цель

Воспроизвести механику Edelkrone JibONE (см. [`../research/edelkrone-jibone-reference.md`](../research/edelkrone-jibone-reference.md))
в виде функционального аналога, управляемого платой с FluidNC.

## Оси движения (черновой список)

| Ось | Аналог у оригинала | Статус |
|---|---|---|
| Подъём/вылет стрелы (основной ход джиба) | Основной ход JibONE, 50 см | не определено |
| Панорамирование (поворот основания) | Встроенный мотор панорамирования (v3) / Pan Module (v1-v2) | не определено |
| Наклон камеры (tilt) | Через сопрягаемую голову HeadONE/HeadPLUS у оригинала | не определено |
