# Механическая конструкция

> **DRAFT** — конструкция ещё не спроектирована. Документ фиксирует известные
> вводные и вопросы, требующие решения до начала проектирования/закупки.

## Цель

Воспроизвести механику Edelkrone JibONE (см. [`../research/edelkrone-jibone-reference.md`](../research/edelkrone-jibone-reference.md))
в виде функционального аналога, управляемого платой с FluidNC.

## Оси движения (черновой список)

| Ось | Название | Диапазон |
|---|---|---|
| X | Подъём/опускание стрелы | -15°..+65° (диапазон будет уточняться) |
| Y | Поворот стрелы | не ограничен |
| Z | Панорамирование камеры | 0°..360° |
| A | Наклон камеры | 0°..360° |

## Приводы

- Тип двигателей (шаговые/сервоприводы) — не выбран.
- Редукторы/передачи (ремень, винт, зубчатая передача) — не выбраны.
- Требуемый крутящий момент/усилие зависит от целевой нагрузки и плеча —
  см. открытый вопрос в референсе.

## Балансировка

Оригинал использует систему противовесов. Нужно решить: повторяем тот же
подход или компенсируем моментом двигателя.
