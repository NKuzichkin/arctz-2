# Подписи джойстиков + чистка подсказок из меню программы

## Контекст

Сейчас подсказки о назначении джойстиков реализованы как `ToolTip.Tip` на самих
`VirtualJoystick` (`MainView.axaml`, строки 214/218) и дублируются коротким
описательным текстом в разделе «ПРОГРАММА» (строки 135-136). Приложение — тачскрин
в приоритете (мобильные/планшет); всплывающие `ToolTip` там практически бесполезны
(наведения мышью нет), а дублирующий текст в разделе программы занимает место и
устаревает независимо от самих джойстиков.

Отдельно у пунктов Flyout-меню раздела «ПРОГРАММА» есть свои `ToolTip.Tip`
(«Захватить» — строка 149, «На точку» — строка 171), которые тоже не нужны.

## Требования

1. У каждого джойстика — постоянно видимая подпись снизу (не всплывающая
   подсказка), которая не перекрывается пальцем при работе с джойстиком.
2. Из раздела «ПРОГРАММА» убрать дублирующий текстовый блок с описанием
   джойстиков и `ToolTip.Tip` у пунктов Flyout-меню «Захватить» и «На точку».
3. Подпись не должна раздувать колонку джойстика в `JoystickBar` шире самого
   джойстика и не должна ломать текущий расчёт радиуса джойстика под размер окна.

## Решение

### 1. Подписи снизу джойстиков

В `MainView.axaml` (`JoystickBar`, строки 211-220) каждый `js:VirtualJoystick`
оборачивается в `StackPanel` (`Orientation="Vertical"`, `Spacing="4"`,
`HorizontalAlignment="Center"`, `VerticalAlignment="Center"`): джойстик сверху,
`TextBlock`-подпись снизу. `ToolTip.Tip` с джойстиков удаляется.

Текст подписей (короче нынешнего tooltip'а — постоянно видимый текст должен быть
компактным, буквы осей G-code X·Y/Z·A убираются как несущественные для управления
пальцем):
- Левый джойстик: «Подъём / поворот стрелы»
- Правый джойстик: «Пан / наклон камеры»

Стиль подписи — как у уже существующего описательного текста, который убирается
из раздела «ПРОГРАММА» (см. ниже): `Opacity="0.6"`, `FontSize="12"`,
`TextWrapping="Wrap"`, `TextAlignment="Center"`.

Чтобы подпись не расширяла `Auto`-колонку `JoystickBar` шире диаметра джойстика,
её `MaxWidth` привязывается к текущему радиусу джойстика через уже существующий
`RadiusToSizeConverter` (`ArctZ/Components/VirtualJoystick/RadiusToSizeConverter.cs`,
`radius * 2`), зарегистрированный как новый ресурс `RadiusToSize` в
`MainView.axaml`:

```xml
<TextBlock MaxWidth="{Binding Radius, ElementName=LeftJoystick, Converter={StaticResource RadiusToSize}}" .../>
```

### 2. Поправка формулы радиуса джойстика

`MainView.axaml.cs` (`ComputeJoystickRadius`) сейчас считает
`heightRadius = joystickRowBudget / 2`, исходя из того, что вся высота ряда
джойстиков — это диаметр джойстика. С подписью снизу высота ряда становится
`диаметр + Spacing + высота подписи` (до двух строк при переносе на маленьком
радиусе). Добавляется константа `JoystickLabelReservedHeight = 36`
(≈ 2 строки по 12px + spacing 4), и формула меняется на:

```csharp
var heightRadius = (joystickRowBudget - JoystickLabelReservedHeight) / 2;
```

Существующий `Math.Clamp(..., MinRadius, MaxRadius)` не меняется — подпись всегда
помещается в зарезервированный бюджет независимо от итогового радиуса.

### 3. Чистка подсказок из меню программы

В `MainView.axaml`:
- Строки 135-136 — удаляется `TextBlock` с текстом «Левый джойстик —
  подъём/поворот стрелы (X·Y). Правый — пан/наклон камеры (Z·A).» (дублирует
  новые подписи у джойстиков).
- Строка 149 — удаляется `ToolTip.Tip="Нужно подключение к станку и известная
  текущая позиция"` у `MenuItem Header="Захватить"`.
- Строка 171 — удаляется `ToolTip.Tip="Отправить станок к этой точке"` у
  `MenuItem Header="На точку"`.

Сами команды и пункты меню не меняются — удаляются только подсказки.

## Вне рамок

- Логика самих джойстиков (`VirtualJoystick.cs`, обработка pointer-событий) не
  меняется.
- `ToolTip.Tip="Отключить"` в шапке (строка 101) — не подсказка о работе
  джойстиков/программы, не трогается.
- Адаптация подписей под очень узкие экраны (`narrow-screen` режим) — если текущая
  адаптивная раскладка джойстиков (см. `2026-07-30-narrow-joystick-half-width-design.md`)
  потребует отдельной подгонки, это разбирается по факту при UI-проверке, а не
  заранее.

## Проверка

Стандартный воркфлоу проекта: собрать `ArctZ.Desktop`, запустить, попросить
пользователя проверить — подписи видны и не перекрываются при работе с джойстиком,
текст читаем при разных размерах окна, джойстики по-прежнему масштабируются без
обрезки/наложения, подсказки в меню программы (текстовый блок и tooltip'ы пунктов)
отсутствуют. По каждому пункту — вопрос через `AskUserQuestion`.
