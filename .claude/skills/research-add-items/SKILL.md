# Research Add Items — дополнение объектов исследования

## Триггер
`/research-add-items`

## Рабочий процесс

### Шаг 1: Автоматический поиск плана
Найти файл `*/outline.yaml` в текущем рабочем каталоге, автоматически прочитать.

### Шаг 2: Получить источники дополнения параллельно
Одновременно:
- **A. Спросить пользователя**: какие элементы дополнить? Есть ли конкретные названия?
- **B. Спросить, нужен ли веб-поиск**: запустить агента для поиска дополнительных элементов?

### Шаг 3: Объединить и обновить
- Добавить новые элементы в outline.yaml
- Показать пользователю для подтверждения
- Избегать дублирования
- Сохранить обновлённый план

## Результат
Обновлённый файл `{topic}/outline.yaml` (изменение на месте)
