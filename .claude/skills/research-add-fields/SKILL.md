# Research Add Fields — дополнение полей исследования

## Триггер
`/research-add-fields`

## Рабочий процесс

### Шаг 1: Автоматический поиск файла полей
Найти файл `*/fields.yaml` в текущем рабочем каталоге, автоматически прочитать существующие определения полей.

### Шаг 2: Получить источник дополнения
Спросить пользователя, что выбрать:
- **A. Прямой ввод пользователем**: пользователь предоставляет названия и описания полей
- **B. Веб-поиск**: запустить агента для поиска распространённых полей в этой области

### Шаг 3: Показать и подтвердить
- Показать список предлагаемых новых полей
- Пользователь подтверждает, какие поля добавить
- Пользователь указывает категорию поля и detail_level

### Шаг 4: Сохранить обновление
Добавить подтверждённые поля в fields.yaml, сохранить файл.

## Результат
Обновлённый файл `{topic}/fields.yaml` (изменение на месте, требует подтверждения пользователя)
