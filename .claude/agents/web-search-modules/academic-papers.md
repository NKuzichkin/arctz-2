# Модуль научных статей

> Специализированная стратегия для поиска научных статей, выделенная из web-search-agent.md

**Сценарий применения**: поиск статей, научные исследования, принципы алгоритмов

## Источники поиска (Academic Sources)
- **Google Scholar** (scholar.google.com) — универсальная поисковая система по научным публикациям
- **arXiv** (arxiv.org) — препринты по физике, математике, информатике и смежным областям
- **Hugging Face Papers** (huggingface.co/papers) — ежедневные/ежемесячные трендовые статьи по ML/AI с оценками сообщества
- **bioRxiv** (biorxiv.org) — препринты по биологии и наукам о жизни
- **ResearchGate** (researchgate.net) — научная социальная сеть со статьями и профилями авторов
- **Semantic Scholar** (semanticscholar.org) — научный поиск на основе ИИ
- **ACM Digital Library** и **IEEE Xplore** — статьи по информатике и инженерии

## Стратегия запросов (1.3 Поиск научных статей)
- Использовать Google Scholar как основной источник с расширенными операторами поиска
- Искать по именам авторов, названиям статей, номерам DOI, организациям и годам публикации
- Использовать кавычки для точных названий и сочетаний имён авторов
- Указывать диапазоны лет для поиска основополагающих работ и недавних публикаций
- Искать связанные статьи и паттерны цитирования для выявления основополагающих работ
- Искать препринты на arXiv, bioRxiv и в институциональных репозиториях
- Проверять профили авторов и ResearchGate на наличие публикаций и PDF
- Определять версии с открытым доступом и легальные источники загрузки статей
- Отслеживать сети цитирования для понимания эволюции исследования
- Отмечать импакт-факторы, h-индекс и количество цитирований для оценки релевантности
- Искать материалы конференций, журналы и статьи workshop
- Определять финансирующие организации и научные гранты для контекста
