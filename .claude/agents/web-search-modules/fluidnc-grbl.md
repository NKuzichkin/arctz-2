# Модуль документации FluidNC и GRBL

> Специализированная стратегия поиска по документации прошивок FluidNC/GRBL

**Сценарий применения**: команды G-code, настройка $-параметров/YAML-конфигурации, поведение прошивки ЧПУ, различия между FluidNC и классическим GRBL

## Источники поиска
- **FluidNC Wiki** (wiki.fluidnc.com) — основной официальный источник по конфигурации (YAML), командам и подключению периферии
  - ⚠️ Блокирует прямой WebFetch (ECONNREFUSED) — используйте прокси-префикс `https://r.jina.ai/` перед URL
- **FluidNC GitHub** (github.com/bdring/FluidNC) — issues, обсуждения, исходники, releases, changelog
- **GRBL Wiki** (github.com/gnea/grbl/wiki) — официальная документация классического GRBL ($-параметры, G-code, real-time команды)
- **GRBL GitHub** (github.com/gnea/grbl) — issues и исходники классического GRBL
- **LinuxCNC G-code Reference** (linuxcnc.org/docs) — независимый справочник по стандартным G/M-кодам (RS274/NGC) для сверки семантики команд
- **Reddit** (r/hobbycnc, r/CNC) и **Discord-сообщества FluidNC/GRBL** — практический опыт настройки конкретного железа

## Стратегия запросов
- Искать точные номера $-параметров и YAML-ключи в кавычках (напр. `"$130"`, `"stepping:"`, `"tmc_2209:"`)
- Искать точные G/M-коды в кавычках (напр. `"G28.1"`, `"M3"`) вместе с названием прошивки
- Явно различать: это стандартная команда GRBL 1.1, или расширение/особенность, специфичное для FluidNC
- Проверять версию прошивки — поведение и набор команд отличаются между GRBL 1.1, FluidNC 3.x и более старыми ветками FluidNC
- При работе с wiki.fluidnc.com сразу использовать прокси `r.jina.ai/<url>`, не тратя попытку на прямой WebFetch
- Сверять описание YAML-конфигурации на wiki с реальными примерами `config.yaml` в issues/обсуждениях — документация нередко отстаёт от кода
- Для проблем с конкретным железом (шаговые драйверы, концевики, Bluetooth/WiFi-модули) искать по названию платы/драйвера + FluidNC
