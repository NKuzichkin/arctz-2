# Модуль GitHub Debug

> Специализированная стратегия для GitHub/отладки, выделенная из web-search-agent.md

**Сценарий применения**: баги в проектах, отладка ошибок, поиск issue, проблемы, специфичные для версии

## Источники поиска
- **GitHub Issues** (открытые и закрытые) — отлично подходят для известных багов и обходных путей

## Стратегия запросов (1.1 Помощь в отладке)
- Искать точный текст сообщения об ошибке в кавычках
- Искать шаблоны issue, соответствующие паттерну проблемы
- Искать обходные пути (workarounds), а не только объяснения
- Проверять, является ли это известным багом с существующими патчами или PR
- Искать похожие issue, даже если они не совпадают точно
- Определять, специфична ли проблема для конкретной версии
- Искать как по названию библиотеки + ошибка, так и по более общим описаниям
- Проверять закрытые issue на паттерны решения
