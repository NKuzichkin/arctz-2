# Модуль китайских технических ресурсов

> Специализированная стратегия для китайского технического сообщества, выделенная из web-search-agent.md

**Сценарий применения**: технические вопросы на китайском языке, отечественные (китайские) фреймворки, решения из китайских сообществ

## Источники поиска (Chinese Technical Sites)
- **CSDN** (csdn.net) — крупнейшее IT-сообщество Китая с обширными техническими статьями и решениями
- **Juejin** (juejin.cn) — качественное китайское сообщество разработчиков с фокусом на современные технологии
- **SegmentFault** (segmentfault.com) — китайская платформа вопросов и ответов, аналог Stack Overflow
- **Zhihu** (zhihu.com) — китайская платформа обмена знаниями с техническими обсуждениями
- **Cnblogs** (cnblogs.com) — китайская блог-платформа с глубоким техническим контентом
- **OSChina** (oschina.net) — китайское сообщество открытого исходного кода и технические новости
- **V2EX** (v2ex.com) — китайское сообщество разработчиков с активными обсуждениями
- **Tencent Cloud** и **Alibaba Cloud** — сообщества разработчиков корпоративного уровня

## Стратегия запросов (двуязычное исследование)
- **Для двуязычного исследования**: формировать запросы как на английском, так и на китайском (中文) языках
- Использовать китайские технические термины и их распространённые переводы (например, "报错" для обозначения ошибок, "解决方案" для решений)
- Искать на китайских сайтах с китайскими ключевыми словами для получения лучших результатов из китайских сообществ разработчиков
